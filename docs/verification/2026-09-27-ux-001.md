# UX-001 Verification — 2026-09-27

Scope: accessibility, keyboard use and error states of the core workflow (AC-14). Branch `ux-001`.

## Acceptance criteria (set before changes)

1. axe-core finds no WCAG 2.2 A/AA violations on every main screen, desktop and 360 px.
2. The core workflow (household → recipe → order → shopping) works keyboard-only at 360 px, and no control reached with Tab is hidden behind the fixed bottom navigation.
3. An ended session returns the user to sign-in with an explanation; offline and server failures show plain messages and recover.
4. Each page has its own document title.

## Environment

Owner's Mac, Node 24.19.0, PostgreSQL 14.18, Playwright 1.63.0 Chromium; new dev dependency `@axe-core/playwright` 4.13.0 (axe-core 4.13.0; runtime audit unchanged, 0 vulnerabilities).
