## Acceptance criteria

1. Sign out asks for confirmation. Cancel retains the session; confirm signs out once. The dialog has an accessible name and returns focus after cancellation.
2. Desktop recipe photo drag-and-drop uses the same validation/upload path as file selection. The file picker remains available. A phone displays an obvious upload button.
3. The browser has a project icon, with a 180 px Apple touch icon; neither asset uses a stock photograph.
