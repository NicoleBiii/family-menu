Date: 2026-10-05. Branch: `codex/rec-002-bulk-import-plan`. Implementation commit: `48592bf`. [PR #38](https://github.com/NicoleBiii/family-menu/pull/38). Status: local checks and PR Quality checks passed; merged as `06c8ac3` and deployed to staging; owner review pending.

## Change

- `/recipes/import` gives an active member copyable English/Chinese AI instructions and a version 1 JSON example, then a paste → preview → explicit category mapping/duplicate choice → commit flow. The app does not call an AI model for this import.
- API preview validates up to 50 recipes and shows category/duplicate/capacity information without saving recipes or categories. Commit rechecks it under a household lock and saves selected recipes and new categories in one transaction. A persisted request receipt makes retries idempotent; the same request ID with different content conflicts.
- Request bodies are bounded at 512 KiB, with household preview/commit rate windows. Existing individual recipe and category creation now share the household capacity lock. Migration 010 adds operation receipts and rate counters, with existing runtime-role setup granting the new tables when run after migration.
- OpenAPI regenerated. The recipe source stays `manual`; import operation metadata records its batch, while model output from an external assistant is never mislabeled as an internal AI draft.
