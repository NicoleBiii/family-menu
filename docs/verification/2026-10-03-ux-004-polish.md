# UX-004 Owner UI Polish — 2026-10-03

Scope: four interface changes the owner requested on 2026-10-03, before the production setup. Branch `claude/ux-004-polish`, based on `main` at `08307a2`. Web-only; no API, migration or dependency change.

| Request                                                      | Change and evidence                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The recipe card's × scrolls out of view                      | The dialog header (eyebrow and close button) is sticky at the top of the card. `shell.spec.ts` scrolls a starter recipe card to its end at 360 × 640; the close button stays in the viewport and closes the card                                                                                                                                                  |
| Long Home and Recipes pages need a one-tap return to the top | A Back to top button appears after more than one screen of scrolling, on every page (Shopping lists get long too). It sits above the bottom navigation and, on narrower screens, above the floating basket. It respects reduced motion and moves focus to the skip link. Tested: hidden at the top, visible after scrolling, returns to `scrollY = 0`, then hides |
| Dishes already ordered are not prominent enough              | A chosen dish gets a tinted background, a dark left bar, an "In basket · N" / "已点 N 份" label and a count badge on its photo. The category rail shows each category's chosen servings as a badge, with screen-reader text ("Soups 3 in basket"). `basket.spec.ts` asserts the rail names and the highlighted and unhighlighted dishes                           |
| AI drafting should be the main way to add a recipe           | Recipes opens with a full-width "Draft with AI" card and a one-line explanation; "Add recipe" becomes a secondary button. The AI draft browser cases pass through the new card                                                                                                                                                                                    |
